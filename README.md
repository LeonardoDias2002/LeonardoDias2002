### 🔬 Featured Projects

* **[Longitudinal Prediction in Parkinson's Disease](https://github.com/LeonardoDias2002/parkinson-predictive-model)**: 
  A predictive model using LightGBM to forecast the motor degradation of patients (MDS-UPDRS), focusing on local explainability (SHAP) and correction of observational bias. Includes an interactive clinical web application.
* **[The Home Advantage in the Premier League](https://github.com/LeonardoDias2002/premier-league-home-advantage)**:
  Data analysis and hypothesis testing on the impact of stadium attendance on English clubs' performance, comparing pre-pandemic data with closed-door seasons.
* **[Optimization: Hybrid VNS Heuristic](https://github.com/LeonardoDias2002/vns-heuristic-optimization)**:
  Implementation of a Variable Neighborhood Search algorithm to solve complex combinatorial optimization problems.
